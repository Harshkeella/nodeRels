Now, let's talk about the decision boundary in logistic regression. Imagine you have a probability value, and you decide to turn it into a hard label. Typically, you set a threshold of 0.5. If the probability is 0.5 or higher, you classify it as class 1. If it's lower than 0.5, you classify it as class 0. This threshold translates into a condition on the raw linear score. Specifically, you predict class 1 whenever the dot product of theta and x is greater than or equal to zero. Geometrically, the equation theta transpose x equals zero defines a hyperplane in feature space. In a two-dimensional space, this hyperplane is a straight line, and in three-dimensional space, it's a flat plane. Everything on one side of this line or plane is classified as class 1, and everything on the other side is classified as class 0. This is why plain logistic regression is a linear classifier. The boundary it draws is always straight, even though the probability surface curves smoothly through it. For non-linear boundaries, you would need to engineer features like x squared terms or use a non-linear model.
