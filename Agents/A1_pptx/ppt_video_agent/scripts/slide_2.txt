Okay, let's dive into why we can't just use linear regression for classification problems. Imagine you're trying to decide if an email is spam or not. The answer is a yes or no, but linear regression gives us a score that can go from negative infinity to positive infinity. That's a bit like trying to fit a ruler that can measure from minus infinity to plus infinity into a space that only needs to measure between 0 and 1. It just doesn't fit!

So, why not use linear regression? Well, the problem is that the output from linear regression can go way beyond the 0 to 1 range, which doesn't make sense for probabilities. For example, if you get a score of 200, that doesn't mean the email is 200 times more likely to be spam. We need a way to make sure our output stays between 0 and 1.

That's where logistic regression comes in. Logistic regression does something clever. It takes the same linear combination of features that linear regression uses, but then it passes that score through a special function called the sigmoid function. This function squeezes the score into a range between 0 and 1, making it perfect for probabilities.

Here's how it works: First, we compute a linear combination of the features, just like in linear regression. We call this score \( z \). Then, we pass \( z \) through the sigmoid function, which looks like this: \( \frac{1}{1 + e^{-z}} \). This function always gives us a value between 0 and 1, no matter what \( z \) is. We interpret this result as the probability that the positive class is true, or in other words, \( P(y = 1 | x) \).

To make a final decision, we compare this probability to a threshold, usually 0.5. If the probability is greater than 0.5, we classify it as the positive class. If it's less than 0.5, we classify it as the negative class.

So, that's the core idea of logistic regression: it uses a linear combination of features, but then it squashes that score through the sigmoid function to get a valid probability. And that's why we use logistic regression for classification problems.
